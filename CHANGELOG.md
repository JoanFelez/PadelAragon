# Changelog

All notable changes to this project are documented in this file.

## [2.1.0] - 2026-09-25

### Added

- League selection for Absoluta, Veteranos, and Menores, with remembered selection.
- Player detail screens with summary statistics and home/away match history.
- Veteranos possible-pairs generation with the desktop eligibility rules.

### Changed

- League-scoped cached data and favourites to prevent data from one league appearing in another.
- Contextual retry behavior for unavailable player and possible-pairs data.
